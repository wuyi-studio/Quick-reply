# 梧藝客服小幫手（Chrome 側邊欄）安裝說明

## 安裝
1. 把 `wuyi-quick-reply-extension.zip`（或 `梧藝客服小幫手_Chrome擴充.zip`）解壓縮，放在一個不會被刪掉的資料夾（例如「文件」）。
2. 在 Chrome 網址列輸入 `chrome://extensions` 並按 Enter。
3. 打開右上角的「開發人員模式」。
4. 按左上角的「載入未封裝項目」。
5. 選擇剛剛解壓縮的 `wuyi-quick-reply-extension` 資料夾（裡面要看得到 `manifest.json`）。
6. 按 Chrome 右上角的拼圖圖示 🧩，把「梧藝客服小幫手」釘選到工具列。

## 使用
1. 打開 LINE 官方帳號網頁版聊天：<https://chat.line.biz/>，點開要回覆的客人對話。
2. 按工具列上綠色的「梧」圖示，右側會打開小幫手側邊欄。
3. 直接點一下回覆卡片（✏️ 編輯、📋 複製按鈕以外的地方），文字就會填進目前客人的對話框：
   - 對話框原本有字時，會換一行接在後面，不會蓋掉。
   - **不會自動傳送**，請確認內容和客人沒錯後，自己按「傳送」（或 Command + Enter）。
4. 報價試算器和上方臨時編輯框則是按「📥 貼上」按鈕，用法相同。
   - 卡片上的「移動」可打開移動欄位與換頁視窗；滑鼠拖曳仍可換位。這兩種操作都不會貼上。沒有長按三秒選單。
   - 每頁格數可選 10、15 或 20 格。改少時，多出來的格子只是不顯示，不會刪除。
5. 想要獨立的小視窗：按標題列的 🪟「切換成小視窗」，會在螢幕右側開一個可拖曳、可調大小的小視窗（會記住大小和位置）；在小視窗按 🗂️「切回側邊欄」即可回來。小視窗會貼到你最後使用的 Chrome 視窗目前開著的分頁。
6. 貼不進去時，側邊欄下方會出現「📋 複製診斷資訊」按鈕：按下後把複製到的內容貼給系統部（只有網址路徑和輸入框數量，不含任何訊息內容）。文字也會先複製好，可以手動貼上。

## 注意
- 只會貼到「目前畫面上開著的那個對話」，切換客人後請再確認一次。
- 擴充功能裡的常用回覆資料和網頁版（GitHub 網址）是分開存的。要搬資料：在網頁版按「⚙️ 管理／匯入 → 💾 備份下載」，再到側邊欄按「📂 還原匯入」選那個檔案。
- 側邊欄可能無法使用麥克風；語音輸入不能用時按鈕會自動隱藏，請改用打字。
- 之後 LINE 網頁改版，若貼不進去，請通知系統部調整。
- 更新版本：把新資料夾覆蓋舊的，再到 `chrome://extensions` 按擴充功能上的重新整理 ↻。
- 直接把 ZIP 拖進 Chrome **不會**安裝，一定要先解壓縮，再用「載入未封裝項目」選資料夾。
